Generate API Key Explore REST Docs
Tenant Isolation & Hashing
API keys are hashed via SHA-256. Keys can only access records from your connected Google Sheet workspace.
Rate Limiting
Standard rate limits at 100 requests/minute per API Key, with standard HTTP 429 status codes on overflow.
Real-time Webhooks
Receive HTTP POST notifications when invoices are created, payments received, or quotations accepted.
Quick Start

Make your first API call with your API key from the header:

# Get all invoices
curl -X GET "https://your-backend.com/api/v1/invoices" \
-H "x-api-key: YOUR_API_KEY"
# Create a new invoice
curl -X POST "https://your-backend.com/api/v1/invoices" \
-H "x-api-key: YOUR_API_KEY" \
-H "Content-Type: application/json" \
-d '{"customer_name":"Acme Corp","total":18500}'
Supported Endpoints
GET /api/v1/invoices List all invoices
POST /api/v1/invoices Create invoice
GET /api/v1/quotations List all quotations
POST /api/v1/quotations Create quotation
GET /api/v1/customers List all customers
POST /api/v1/customers Create customer
GET /api/v1/products List all products
